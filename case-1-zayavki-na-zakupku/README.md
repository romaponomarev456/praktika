# Кейс 1. Поиск нетипичного поведения заявок на закупку

## Структура папки

- `source/` — исходные материалы задания (как выданы):
  - `task.md` — условие задания
  - `submission_template.md` — формат сдачи
  - `dataset_description.md` — описание журнала событий
  - `students.csv` — исходная выгрузка событий (1000 процессов)
- `anomalies.csv` — результат: список найденных аномалий (`ProcessInstanceId, AnomalyType, Explanation`)
- `report.md` — краткий отчёт по пунктам из `submission_template.md`
- `analysis.py` — воспроизводимый код анализа на pandas (без ML)

## Как воспроизвести

```bash
cd case-1-zayavki-na-zakupku
python3 analysis.py   # ожидает students.csv рядом; при необходимости скопируйте его из source/
```

## Краткая суть результата

Найдено 64 уникальных процесса с отклонениями (72 строки в `anomalies.csv`, часть процессов — с двумя
отклонениями), сгруппированных в 8 типов: пропущенный обязательный этап согласования руководителем,
несоответствие роли этапу (самоодобрение), аномально долгая проверка специалиста, нарушение порядка
этапов, подозрительно быстрое прохождение всего маршрута, избыточные циклы доработки, повторная проверка
специалиста без возврата, «зависшие» задания. Подробности и обоснования — в `report.md`.
